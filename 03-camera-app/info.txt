EXERCISE 3 - GESTURE-CONTROLLED CAMERA APP
===========================================

A gesture-controlled camera application that uses a CNN to recognize hand gestures
in real time via webcam. Due to time constraints, gesture recognition via the model
did not work reliably in practice, so the submitted version maps keyboard keys to gestures to allow the
camera effects to be tested. A physical ArUco board as a bounding box for the region
of interest was also attempted but did not improve results.

FILES
=====

camera_app.py
-------------
Main script. Handles gesture input (keyboard or CNN prediction), selfie countdown,
photo saving, and two additional camera effects: portrait mode and sepia filter.
Uses argparse for command line arguments.

camera_app_model.ipynb
-----------------------
Notebook used to train the gesture classifier. Uses the same architecture and
preprocessing pipeline as Exercise 1 (Grayscale, best performing color mode),
with three gesture classes: like, stop and rock.

model_cam_grayscale.keras
------------------------------------------------------
Trained model for the camera app gesture classifier.

pictures/
---------
Folder where example photos are saved and which can be selected as the saving path.

NOTES
=====
- The model was trained on a subset of the HaGRID dataset. It performed well on
  the test set.
- Keyboard controls: 1 (like), 2 (stop), 3 (rock), Space (predict), Q (quit).
