EXERCISE 1 - HYPERPARAMETER EXPLORATION: IMAGE COLOR MODE
==========================================================

Explores the effect of image color mode on CNN prediction accuracy and
convergence speed. Five color spaces are tested: RGB, Grayscale, HSV, LAB,
and YCrCb. A separate model is trained for each using a subset of the HaGRID
dataset, and results are compared via validation accuracy, validation loss,
epochs until convergence, and confusion matrices.

FILES
=====

image_color_mode.ipynb
----------------------
Main notebook. Contains the full pipeline: data loading, preprocessing,
model training, evaluation, and result visualization for all five color
spaces. Also includes the theoretical background and discussion of results.

hyperparameters.ipynb
---------------------
Original notebook provided in class. Used as the base for image_color_mode.ipynb.

NOTES
=====
- The dataset path must be updated at the top of the notebook before running.
- The HaGRID dataset subset must be downloaded separately from GRIPS.
- Models are saved as .keras files after training.
